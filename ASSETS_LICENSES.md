# Assets & Licensing

## Built-in Local Asset Pack

All bundled audio assets under `public/assets/` are procedurally generated by the project script:

- Script: `scripts/generate-assets.mjs`
- Manifest: `public/assets/metadata/asset-manifest.json`
- License for generated files: MIT (same as repository)

Included generated files:

- `public/assets/samples/snare.wav`

## Optional Remote Assets

### Freesound API (Optional)

- Source: Freesound user-uploaded content
- API: `https://freesound.org/apiv2/`
- License/attribution is per individual sound item
- The app returns metadata needed for attribution (`username`, `license`, `url`)

If you use downloaded Freesound assets externally, you must comply with each asset’s license terms.

### Pixabay API (Optional)

- Source: Pixabay media catalog
- API docs: `https://pixabay.com/api/docs/`
- Usage governed by Pixabay terms/license

## Safety Policy in This Repo

- No unclear-license external assets are bundled in repository defaults.
- Core app functionality does not require external asset downloads.
- Optional integrations are non-blocking and explicitly marked in UI/docs.
