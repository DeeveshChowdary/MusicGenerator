# LoFi Foundry

LoFi Foundry is a browser-based lo-fi hip-hop generator built with Next.js + Tone.js.
It generates coherent endless study beats in real time with deterministic seed-based music generation, layer locks, local session recall, and WAV export.

## What You Get

- Real-time lo-fi generator with transport controls (play/pause/stop/regenerate/evolve)
- 10 mood presets:
  - Rainy Night
  - Coffee Shop
  - Midnight Study
  - Soft Jazz
  - Vinyl Dreams
  - Nostalgic Tape
  - Sleepy Tokyo
  - Warm Sunset
  - Winter Window
  - Spacey Chill
- Deterministic generation by seed (same seed + controls = same loop)
- Multi-layer engine:
  - Harmony (voice leading, color chords, templates)
  - Drums (swing + humanization + fills)
  - Bass (root/passing tones with sparse behavior)
  - Melody motifs (density-aware, call-response)
  - Ambience texture layer
- Layer locks + reseed-one-layer workflow
- Synth and sample-based drums (local built-in sample pack)
- Audio mixer with buses/effects (filter, compressor, limiter, wow/flutter, reverb, delay)
- Loop visualization + layer meters
- Session save/load in localStorage
- Session JSON copy/import + project state download
- WAV export (offline rendered loop)
- Optional free integrations:
  - Freesound search (textures/ambience)
  - Pixabay image search (scene visuals)
- Fully working no-key fallback mode

## Tech Stack

- Next.js 16 (App Router)
- TypeScript (strict)
- Tailwind CSS v4
- Zustand state management
- Tone.js audio engine
- Framer Motion animation
- Vitest for tests

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Environment Variables (Optional APIs)

Copy `.env.example` to `.env.local` and add keys only if you want optional integrations.

```bash
cp .env.example .env.local
```

### 1. Freesound (optional)

- Create a free API key: https://freesound.org/apiv2/apply/
- Set:
  - `NEXT_PUBLIC_FREESOUND_API_KEY=...`

### 2. Pixabay (optional)

- Create a free API key: https://pixabay.com/api/docs/
- Set:
  - `NEXT_PUBLIC_PIXABAY_API_KEY=...`

If keys are missing, LoFi Foundry still works fully with built-in local assets.

## How Generation Works

1. `seed` is split per layer via hashed salts (`harmony`, `drums`, `bass`, `melody`, `ambience`, `arrangement`).
2. Harmony chooses curated progression templates and applies voice leading + bounded inversions.
3. Drum engine uses style templates with probabilistic hit gating, swing offsets, velocity jitter, and fills.
4. Bass follows harmony with sparse motion and optional passing tones.
5. Melody engine creates motifs, silence, and call-response behavior based on density.
6. Ambience chooses texture profile and gain/noise characteristics.
7. Arrangement sections are generated (intro/main/strip/variation/outro) for longer-form planning/export context.

See [`ARCHITECTURE.md`](./ARCHITECTURE.md) for deeper details.

## Running Without API Keys

No external keys are required for core functionality.

- Built-in local sample pack lives in `public/assets/`.
- Generator + playback + export + sessions work offline.
- API asset finder gracefully shows setup guidance when keys are missing.

## Deployment (Vercel)

1. Push repository to GitHub.
2. Import project in Vercel.
3. Add optional env vars in Vercel project settings if desired:
   - `NEXT_PUBLIC_FREESOUND_API_KEY`
   - `NEXT_PUBLIC_PIXABAY_API_KEY`
4. Deploy.

## Browser Audio Troubleshooting

- Audio context unlock requires user gesture in browsers. Click `Play` first.
- If silent:
  - Confirm system output device
  - Check tab permissions
  - Try stopping other apps with exclusive audio output
- If stutter appears, reduce CPU load (close heavy tabs/apps).
